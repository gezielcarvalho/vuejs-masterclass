# Learning charter

## Objective

Practice modern Vue frontend techniques through a job-search-themed interface: TypeScript components, Vue Router, Pinia state, dependency-injection examples, simulated services, Tailwind CSS, and unit-test tooling.

## Scope represented today

- Vite-powered Vue 3 single-page application structure.
- Route configuration and lazy-loaded view components.
- Pinia stores and simulated job, team, and student services.
- Component/unit-test setup with Vitest and Vue Testing Library.
- Frontend linting, formatting, type-check, build, and coverage commands.

## Not in scope

- A real hiring workflow, job application process, candidate data lifecycle, or corporate website.
- Backend API, authentication, authorization, persistent storage, analytics, accessibility audit, or content-management process.
- Production release/deployment, observability, security review, or support ownership.

## Ownership and decision gate

This is a personal learning artifact. It can demonstrate Vue ecosystem familiarity but should stay distinct from `sabre-software` branding and any real English4Devs or corporate hiring operation.

## Criteria for a future product candidate

1. Replace simulated services with an approved API contract and environment configuration.
2. Define data privacy, authorization, and content ownership boundaries.
3. Remove stale/generated tracked artifacts and establish source/build conventions.
4. Expand test coverage, accessibility verification, CI, and release evidence.
5. Obtain brand/content approval before presenting any corporate-facing experience.
